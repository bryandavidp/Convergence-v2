## Protocolo de actualización

Al sustituir o añadir una captura:

1. usar 390 × 844 px para mantener la referencia comparable;
2. abrir un perfil local de QA, nunca datos reales;
3. esperar fuentes e imágenes;
4. capturar el estado estable, excepto cuando se documenta una fase animada;
5. usar el siguiente prefijo numérico;
6. enlazarla desde este índice y desde la pantalla/modal correspondiente en
   [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md);
7. validar PNG, dimensiones y enlace.
